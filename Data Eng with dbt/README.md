# Data Engineering with dbt

A hands-on project exploring **dbt Core** to build, test and manage reliable data transformation workflows.

## Overview
This project covers the fundamentals of developing and managing a dbt project.

## Key Skills
- **Data Transformation:** SQL, dbt Core
- **Project Management:** dbt project structure, models, and configurations
- **Data Quality:** Testing and validating transformed data
- **Development Workflows:** Version control with Git & GitHub
- **Deployment:** Introduction to production dbt workflows

## Tech Stack
`SQL` · `dbt Core` · `Git` · `GitHub`

## Project Goal
Develop practical data engineering skills by learning how to structure transformations, improve data reliability, and build maintainable analytics workflows using dbt.
